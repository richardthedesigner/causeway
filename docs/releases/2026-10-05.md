### If a build is skipped when it should have run

`vercel-ignore.sh` skips when only docs, Markdown, `.github`, `db` or `CLAUDE.md` changed since the last built commit. A merge with app changes always builds. If production does not move, open the latest production deployment's build log: "Skip: ..." names the reason. To force a build, redeploy the latest production deployment from the dashboard (this is a deployment, so it counts toward the daily limit).

### If the daily limit hits again

The symptom is a failed or blocked deployment saying "Resource is limited" (`api-deployments-free-per-day`). It is not a code problem. Wait for the reset (Richard has the exact time in Vercel's usage page) and redeploy. Production stays on the last READY deployment in the meantime.
